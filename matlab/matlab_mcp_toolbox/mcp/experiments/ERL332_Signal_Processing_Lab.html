Exp 1 Generation of Waveforms (Continuous and Discrete)
🎯 Aim – Question

How do you generate and plot the following waveforms in both continuous and discrete form using MATLAB?
1. Unit Impulse   2. Unit Step   3. Unit Ramp   4. Sine Signal   5. Cosine Signal

MATLAB — exp1_waveforms.m
% EXPERIMENT 1 - Generation of Waveforms (Continuous and Discrete)
clc; clear; close all;

n = -10:10;        % discrete axis
t = -2:0.001:2;    % continuous axis
tc = 0:0.001:1;  f = 5;   % 5 Hz for sine/cosine

% --- DISCRETE SIGNALS ---
impulse_d = double(n == 0);
step_d    = double(n >= 0);
ramp_d    = n .* double(n >= 0);
sine_d    = sin(2*pi*0.1*n);
cosine_d  = cos(2*pi*0.1*n);

figure('Name','Discrete Signals','NumberTitle','off');
subplot(3,2,1); stem(n,impulse_d,'filled','LineWidth',1.5);
title('Unit Impulse \delta[n]'); xlabel('n'); grid on; axis([-10 10 -0.2 1.3]);
subplot(3,2,2); stem(n,step_d,'filled','LineWidth',1.5);
title('Unit Step u[n]'); xlabel('n'); grid on; axis([-10 10 -0.2 1.3]);
subplot(3,2,3); stem(n,ramp_d,'filled','LineWidth',1.5);
title('Unit Ramp r[n]'); xlabel('n'); grid on;
subplot(3,2,4); stem(n,sine_d,'filled','LineWidth',1.5);
title('Sine sin(0.2\pin)'); xlabel('n'); ylim([-1.3 1.3]); grid on;
subplot(3,2,5); stem(n,cosine_d,'filled','LineWidth',1.5);
title('Cosine cos(0.2\pin)'); xlabel('n'); ylim([-1.3 1.3]); grid on;
sgtitle('Discrete Time Signals','FontWeight','bold');

% --- CONTINUOUS SIGNALS ---
impulse_c = double(abs(t) < 0.01);
step_c    = double(t >= 0);
ramp_c    = t .* double(t >= 0);
sine_c    = sin(2*pi*f*tc);
cosine_c  = cos(2*pi*f*tc);

figure('Name','Continuous Signals','NumberTitle','off');
subplot(3,2,1); plot(t,impulse_c,'LineWidth',2);
title('Unit Impulse \delta(t)'); xlabel('t'); ylim([-0.2 1.5]); grid on;
subplot(3,2,2); plot(t,step_c,'LineWidth',1.5);
title('Unit Step u(t)'); xlabel('t'); ylim([-0.2 1.5]); grid on;
subplot(3,2,3); plot(t,ramp_c,'LineWidth',1.5);
title('Unit Ramp r(t)'); xlabel('t'); grid on;
subplot(3,2,4); plot(tc,sine_c,'LineWidth',1.5);
title('Sine sin(2\pift)'); xlabel('t'); ylim([-1.3 1.3]); grid on;
subplot(3,2,5); plot(tc,cosine_c,'LineWidth',1.5);
title('Cosine cos(2\pift)'); xlabel('t'); ylim([-1.3 1.3]); grid on;
sgtitle('Continuous Time Signals','FontWeight','bold');
Exp 2 Time and Frequency Response of LTI Systems
🎯 Aim – Question

How do you obtain the time domain (impulse & step response) and frequency domain (magnitude & phase) of the following LTI systems using MATLAB?

First Order:
 a) y(n) = x(n) − x(n−1)
 b) y(n) = 0.2x(n) + 0.2x(n−1) + 0.6y(n−1)

Second Order:
 a) y(n) = 0.5x(n) + x(n−1) + 0.5x(n−2)
 b) y(n) = x(n) + 0.9x(n−2) − 0.4y(n−2)

MATLAB — exp2_lti_response.m
% EXPERIMENT 2 - Time and Frequency Response of LTI Systems
clc; clear; close all;

N=50; Nfft=512; n=0:N-1;
imp=[1 zeros(1,N-1)]; stp=ones(1,N);

% System coefficients  b=numerator  a=denominator
b1a=[1,-1];       a1a=[1];
b1b=[0.2,0.2];    a1b=[1,-0.6];
b2a=[0.5,1,0.5];  a2a=[1];
b2b=[1,0,0.9];    a2b=[1,0,0.4];

systems = {b1a,a1a,'1a: y(n)=x(n)-x(n-1)';
           b1b,a1b,'1b: y(n)=0.2x(n)+0.2x(n-1)+0.6y(n-1)';
           b2a,a2a,'2a: y(n)=0.5x(n)+x(n-1)+0.5x(n-2)';
           b2b,a2b,'2b: y(n)=x(n)+0.9x(n-2)-0.4y(n-2)'};

for i = 1:4
    b=systems{i,1}; a=systems{i,2}; ttl=systems{i,3};
    h=filter(b,a,imp); y=filter(b,a,stp);
    [H,w]=freqz(b,a,Nfft);

    figure('Name',['System ' ttl],'NumberTitle','off');
    subplot(2,2,1); stem(n,h,'filled','LineWidth',1.5);
    title('Impulse Response h[n]'); xlabel('n'); ylabel('h[n]'); grid on;
    subplot(2,2,2); stem(n,y,'filled','LineWidth',1.5);
    title('Step Response'); xlabel('n'); ylabel('y[n]'); grid on;
    subplot(2,2,3); plot(w/pi,20*log10(abs(H)+eps),'LineWidth',1.5);
    title('Magnitude Response');
    xlabel('Norm. Freq (\times\pi rad/sample)'); ylabel('Magnitude (dB)'); grid on;
    subplot(2,2,4); plot(w/pi,angle(H)*180/pi,'LineWidth',1.5);
    title('Phase Response');
    xlabel('Norm. Freq (\times\pi rad/sample)'); ylabel('Phase (deg)'); grid on;
    sgtitle(ttl,'FontWeight','bold','FontSize',10);
end

    Exp 7
    FIR and IIR Filter Design
  

  

    

      
🎯 Aim – Question

      
How do you design the following digital filters in MATLAB and plot their magnitude and phase responses?


      Part i – IIR LPF (Fp=4kHz, Fst=6kHz, Rp≤1dB, Rs≥40dB, Fs=24kHz):

       a) Butterworth   b) Chebyshev Type-I


      Part ii – FIR BPF (fp1=20Hz, fp2=30Hz, fs1=10Hz, fs2=40Hz, Rp=0.5dB, Rs=30dB, Fs=100Hz):

       a) Hamming Window   b) Kaiser Window

    

    

      
MATLAB — exp7_filter_design.m


% EXPERIMENT 7 - FIR and IIR Filter Design
clc; clear; close all;

% =========================================================
% PART i : IIR LOW-PASS FILTER
% =========================================================
Fs=24000; Fp=4000; Fst=6000; Rp=1; Rs=40;
Wp=Fp/(Fs/2); Ws=Fst/(Fs/2);

% a) Butterworth LPF
[n_but,Wn_but] = buttord(Wp,Ws,Rp,Rs);
[b_but,a_but]  = butter(n_but,Wn_but,'low');
fprintf('Butterworth LPF  Order = %d\n',n_but);

figure('Name','Butterworth LPF','NumberTitle','off');
[H,f] = freqz(b_but,a_but,1024,Fs);
subplot(2,1,1); plot(f,20*log10(abs(H)+eps),'LineWidth',1.5);
title(sprintf('Butterworth LPF (Order=%d) Magnitude Response',n_but));
xlabel('Frequency (Hz)'); ylabel('Magnitude (dB)'); grid on;
xline(Fp,'--r','Passband'); xline(Fst,'--b','Stopband');
subplot(2,1,2); plot(f,angle(H)*180/pi,'LineWidth',1.5);
title('Phase Response'); xlabel('Frequency (Hz)'); ylabel('Phase (deg)'); grid on;
sgtitle('IIR - Butterworth LPF','FontWeight','bold');

% b) Chebyshev Type-I LPF
[n_cheb,Wn_cheb] = cheb1ord(Wp,Ws,Rp,Rs);
[b_cheb,a_cheb]  = cheby1(n_cheb,Rp,Wn_cheb,'low');
fprintf('Chebyshev Type-I LPF  Order = %d\n',n_cheb);

figure('Name','Chebyshev LPF','NumberTitle','off');
[H,f] = freqz(b_cheb,a_cheb,1024,Fs);
subplot(2,1,1); plot(f,20*log10(abs(H)+eps),'LineWidth',1.5);
title(sprintf('Chebyshev Type-I LPF (Order=%d) Magnitude Response',n_cheb));
xlabel('Frequency (Hz)'); ylabel('Magnitude (dB)'); grid on;
xline(Fp,'--r','Passband'); xline(Fst,'--b','Stopband');
subplot(2,1,2); plot(f,angle(H)*180/pi,'LineWidth',1.5);
title('Phase Response'); xlabel('Frequency (Hz)'); ylabel('Phase (deg)'); grid on;
sgtitle('IIR - Chebyshev Type-I LPF','FontWeight','bold');

% =========================================================
% PART ii : FIR BAND-PASS FILTER
% =========================================================
Fs2=100; fp1=20; fp2=30; fs1=10; fs2=40; Rs2=30;
df    = min(fp1-fs1, fs2-fp2);
N_ord = ceil((Rs2-7.95)/(14.36*(df/Fs2)));
N_fir = N_ord + mod(N_ord+1,2);
Wn_bp = [fp1,fp2]/(Fs2/2);

% a) Hamming Window BPF
b_ham = fir1(N_fir-1, Wn_bp, 'bandpass', hamming(N_fir));
fprintf('FIR BPF Hamming  Order = %d\n',N_fir-1);

figure('Name','FIR BPF Hamming','NumberTitle','off');
[H,f] = freqz(b_ham,1,1024,Fs2);
subplot(2,1,1); plot(f,20*log10(abs(H)+eps),'LineWidth',1.5);
title(sprintf('FIR BPF Hamming (Order=%d) Magnitude Response',N_fir-1));
xlabel('Frequency (Hz)'); ylabel('Magnitude (dB)'); grid on;
xline(fs1,'--b'); xline(fp1,'--r'); xline(fp2,'--r'); xline(fs2,'--b');
subplot(2,1,2); plot(f,angle(H)*180/pi,'LineWidth',1.5);
title('Phase Response'); xlabel('Frequency (Hz)'); ylabel('Phase (deg)'); grid on;
sgtitle('FIR - Hamming Window BPF','FontWeight','bold');

% b) Kaiser Window BPF
beta  = 0.1102*(Rs2-8.7);
b_kai = fir1(N_fir-1, Wn_bp, 'bandpass', kaiser(N_fir,beta));
fprintf('FIR BPF Kaiser  Order = %d  beta=%.4f\n',N_fir-1,beta);

figure('Name','FIR BPF Kaiser','NumberTitle','off');
[H,f] = freqz(b_kai,1,1024,Fs2);
subplot(2,1,1); plot(f,20*log10(abs(H)+eps),'LineWidth',1.5);
title(sprintf('FIR BPF Kaiser (Order=%d) Magnitude Response',N_fir-1));
xlabel('Frequency (Hz)'); ylabel('Magnitude (dB)'); grid on;
xline(fs1,'--b'); xline(fp1,'--r'); xline(fp2,'--r'); xline(fs2,'--b');
subplot(2,1,2); plot(f,angle(H)*180/pi,'LineWidth',1.5);
title('Phase Response'); xlabel('Frequency (Hz)'); ylabel('Phase (deg)'); grid on;
sgtitle('FIR - Kaiser Window BPF','FontWeight','bold');
