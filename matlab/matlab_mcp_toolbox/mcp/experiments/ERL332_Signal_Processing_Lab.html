Exp 1Generation of Waveforms
🎯 Aim – Question

How do you generate and plot Unit Impulse, Unit Step, Unit Ramp, Sine, and Cosine signals in both discrete and continuous form using MATLAB?

MATLAB — exp1_waveforms.m
clc; clear; close all;

% Discrete axis
n = -10:10;

% Continuous axis
t = 0:0.01:4;
f = 1;

% ---- Discrete Signals ----
figure('Name','Discrete Signals');

subplot(3,2,1);
stem(n, n==0, 'filled');
title('Unit Impulse'); xlabel('n'); grid on;

subplot(3,2,2);
stem(n, n>=0, 'filled');
title('Unit Step'); xlabel('n'); grid on;

subplot(3,2,3);
stem(n, n.*(n>=0), 'filled');
title('Unit Ramp'); xlabel('n'); grid on;

subplot(3,2,4);
stem(n, sin(2*pi*0.1*n), 'filled');
title('Sine'); xlabel('n'); grid on;

subplot(3,2,5);
stem(n, cos(2*pi*0.1*n), 'filled');
title('Cosine'); xlabel('n'); grid on;

sgtitle('Discrete Time Signals');

% ---- Continuous Signals ----
figure('Name','Continuous Signals');

subplot(3,2,1);
plot(t, t==0);
title('Unit Impulse'); xlabel('t'); grid on;

subplot(3,2,2);
plot(t, t>=0);
title('Unit Step'); xlabel('t'); grid on;

subplot(3,2,3);
plot(t, t.*(t>=0));
title('Unit Ramp'); xlabel('t'); grid on;

subplot(3,2,4);
plot(t, sin(2*pi*f*t));
title('Sine'); xlabel('t'); grid on;

subplot(3,2,5);
plot(t, cos(2*pi*f*t));
title('Cosine'); xlabel('t'); grid on;

sgtitle('Continuous Time Signals');
Exp 2Time and Frequency Response of LTI Systems
🎯 Aim – Question

How do you obtain the impulse response, step response, magnitude response, and phase response of the following LTI systems using MATLAB?

First Order: a) y(n)=x(n)−x(n−1)   b) y(n)=0.2x(n)+0.2x(n−1)+0.6y(n−1)
Second Order: a) y(n)=0.5x(n)+x(n−1)+0.5x(n−2)   b) y(n)=x(n)+0.9x(n−2)−0.4y(n−2)

MATLAB — exp2_lti_response.m
clc; clear; close all;

N = 50;
imp = [1 zeros(1,N-1)];
stp = ones(1,N);
n   = 0:N-1;

% System coefficients [b = numerator, a = denominator]
B = {[1 -1],   [1];
     [0.2 0.2],[1 -0.6];
     [0.5 1 0.5],[1];
     [1 0 0.9],[1 0 0.4]};

titles = {'1a: y(n)=x(n)-x(n-1)';
          '1b: y(n)=0.2x(n)+0.2x(n-1)+0.6y(n-1)';
          '2a: y(n)=0.5x(n)+x(n-1)+0.5x(n-2)';
          '2b: y(n)=x(n)+0.9x(n-2)-0.4y(n-2)'};

for i = 1:4
    b = B{i,1};  a = B{i,2};
    [H,w] = freqz(b, a, 512);

    figure('Name', titles{i});

    subplot(2,2,1);
    stem(n, filter(b,a,imp), 'filled');
    title('Impulse Response'); xlabel('n'); grid on;

    subplot(2,2,2);
    stem(n, filter(b,a,stp), 'filled');
    title('Step Response'); xlabel('n'); grid on;

    subplot(2,2,3);
    plot(w/pi, 20*log10(abs(H)+eps));
    title('Magnitude (dB)'); xlabel('Norm. Freq'); grid on;

    subplot(2,2,4);
    plot(w/pi, angle(H)*180/pi);
    title('Phase (degrees)'); xlabel('Norm. Freq'); grid on;

    sgtitle(titles{i});
end

Exp 7FIR and IIR Filter Design

  

    
🎯 Aim – Question

      
How do you design the following digital filters in MATLAB and plot their responses?

      IIR LPF (Fp=4kHz, Fst=6kHz, Rp≤1dB, Rs≥40dB, Fs=24kHz): a) Butterworth   b) Chebyshev

      FIR BPF (fp1=20, fp2=30, fs1=10, fs2=40 Hz, Fs=100Hz): a) Hamming   b) Kaiser

    

    

      
MATLAB — exp7_filter_design.m


clc; clear; close all;

% ---- IIR Low-Pass Filter ----
Fs=24000; Fp=4000; Fst=6000; Rp=1; Rs=40;
Wp=Fp/(Fs/2); Ws=Fst/(Fs/2);

% a) Butterworth
[n,Wn] = buttord(Wp,Ws,Rp,Rs);
[b,a]  = butter(n,Wn);
figure; freqz(b,a,1024,Fs);
title(sprintf('Butterworth LPF  Order=%d',n));

% b) Chebyshev Type-I
[n,Wn] = cheb1ord(Wp,Ws,Rp,Rs);
[b,a]  = cheby1(n,Rp,Wn);
figure; freqz(b,a,1024,Fs);
title(sprintf('Chebyshev LPF  Order=%d',n));

% ---- FIR Band-Pass Filter ----
Fs2=100; fp1=20; fp2=30; fs1=10; fs2=40; Rs2=30;
df    = min(fp1-fs1, fs2-fp2);
N_fir = ceil((Rs2-7.95)/(14.36*(df/Fs2)));
N_fir = N_fir + mod(N_fir+1,2);
Wn    = [fp1 fp2]/(Fs2/2);

% a) Hamming Window
b = fir1(N_fir-1, Wn, 'bandpass', hamming(N_fir));
figure; freqz(b,1,1024,Fs2);
title(sprintf('FIR BPF Hamming  Order=%d',N_fir-1));

% b) Kaiser Window
beta = 0.1102*(Rs2-8.7);
b    = fir1(N_fir-1, Wn, 'bandpass', kaiser(N_fir,beta));
figure; freqz(b,1,1024,Fs2);
title(sprintf('FIR BPF Kaiser  Order=%d  beta=%.2f',N_fir-1,beta));
