Exp 1 Generation of Waveforms (Continuous and Discrete)
🎯 Aim – Question

How do you generate and plot the following waveforms in both continuous and discrete form using MATLAB?
1. Unit Impulse Signal   2. Unit Step Signal   3. Unit Ramp Signal   4. Sine Signal   5. Cosine Signal

MATLAB — exp1_waveforms.m 
% EXPERIMENT 1 - Generation of Waveforms (Continuous and Discrete)

First Order:
  a) y(n) = x(n) − x(n−1)
  b) y(n) = 0.2x(n) + 0.2x(n−1) + 0.6y(n−1)

Second Order:
  a) y(n) = 0.5x(n) + x(n−1) + 0.5x(n−2)

Exp 3 Linear Convolution & Circular Convolution
🎯 Aim – Question

How do you perform and verify the following signal operations using MATLAB?
1. Linear Convolution of two sequences
2. Circular Convolution of two sequences
3. Linear Convolution using Circular Convolution (via zero-padding to length L = M+N−1)

MATLAB — exp3_convolution.m 
% EXPERIMENT 3 - Linear Convolution and Circular Convolution

clc;
clear;
close all;

% Input sequences
x = [1, 2, 3, 4];
h = [1, 1, 1];

fprintf('Input x[n] : ');  disp(x);
fprintf('Input h[n] : ');  disp(h);

% =========================================================
%  1. LINEAR CONVOLUTION  (output length = M + N - 1)
% =========================================================
y_linear = conv(x, h);
fprintf('\n1. Linear Convolution y[n]:\n');
disp(y_linear);

% =========================================================
%  2. CIRCULAR CONVOLUTION (zero-pad to equal length N)
% =========================================================
N_circ = max(length(x), length(h));
x_c = [x, zeros(1, N_circ - length(x))];
h_c = [h, zeros(1, N_circ - length(h))];
y_circ = cconv(x_c, h_c, N_circ);
fprintf('\n2. Circular Convolution y[n]  (N = %d):\n', N_circ);
disp(y_circ);

% =========================================================
%  3. LINEAR CONVOLUTION USING CIRCULAR CONVOLUTION
%     Zero-pad both sequences to L = M + N - 1
% =========================================================
L     = length(x) + length(h) - 1;
x_pad = [x, zeros(1, L - length(x))];
h_pad = [h, zeros(1, L - length(h))];
y_lcc = cconv(x_pad, h_pad, L);
fprintf('\n3. Linear via Circular Convolution y[n]  (L = %d):\n', L);
disp(y_lcc);

fprintf('\nVerification (Linear == Linear via Circular): %d\n',...
        max(abs(y_linear - y_lcc)) < 1e-9);

% =========================================================
%  PLOTS
% =========================================================
figure('Name','Experiment 3 - Convolution','NumberTitle','off');

subplot(3,2,1);
stem(0:length(x)-1, x, 'filled', 'LineWidth', 1.5);
title('Input x[n]'); xlabel('n'); ylabel('x[n]'); grid on;

subplot(3,2,2);
stem(0:length(h)-1, h, 'filled', 'LineWidth', 1.5);
title('Impulse Response h[n]'); xlabel('n'); ylabel('h[n]'); grid on;

subplot(3,2,3);
stem(0:length(y_linear)-1, y_linear, 'filled', 'LineWidth', 1.5);
title('1. Linear Convolution'); xlabel('n'); ylabel('y[n]'); grid on;

subplot(3,2,4);
stem(0:N_circ-1, y_circ, 'filled', 'LineWidth', 1.5);
title(sprintf('2. Circular Convolution (N=%d)', N_circ));
xlabel('n'); ylabel('y[n]'); grid on;

subplot(3,2,5);
stem(0:L-1, y_lcc, 'filled', 'LineWidth', 1.5);
title(sprintf('3. Linear via Circular (L=%d)', L));
xlabel('n'); ylabel('y[n]'); grid on;

sgtitle('Convolution Results','FontWeight','bold','FontSize',12);
Exp 4 DFT and IDFT of a Sequence
🎯 Aim – Question

How do you compute the Discrete Fourier Transform (DFT) and Inverse DFT (IDFT) of a given discrete sequence manually using the DFT formula in MATLAB, and verify the result using the built-in fft() function?

DFT  : X(k) = ∑ x(n) · e−j2πkn/N
IDFT : x(n) = (1/N) ∑ X(k) · ej2πkn/N

MATLAB — exp4_dft_idft.m 
% EXPERIMENT 4 - DFT and IDFT of a Sequence
%
% DFT  : X(k) = sum_{n=0}^{N-1} x(n)*exp(-j*2*pi*k*n/N)
% IDFT : x(n) = (1/N) sum_{k=0}^{N-1} X(k)*exp(j*2*pi*k*n/N)

clc;
clear;
close all;

% Input sequence
x = [1, 2, 3, 4];
N = length(x);

fprintf('Input sequence x[n]: ');
disp(x);

% =========================================================
%  MANUAL DFT
% =========================================================
X = zeros(1, N);
for k = 0:N-1
    for n = 0:N-1
        X(k+1) = X(k+1) + x(n+1)*exp(-1j*2*pi*k*n/N);
    end
end

fprintf('\nDFT Magnitude |X(k)|:\n');
disp(abs(X));
fprintf('DFT Phase (degrees):\n');
disp(angle(X)*180/pi);

% =========================================================
%  MANUAL IDFT
% =========================================================
x_rec = zeros(1, N);
for n = 0:N-1
    for k = 0:N-1
        x_rec(n+1) = x_rec(n+1) + X(k+1)*exp(1j*2*pi*k*n/N);
    end
    x_rec(n+1) = x_rec(n+1)/N;
end
x_rec = real(x_rec);

fprintf('\nIDFT reconstructed x[n]:\n');
disp(x_rec);
fprintf('Max reconstruction error: %.2e\n', max(abs(x - x_rec)));

% Verify with built-in fft
X_builtin = fft(x);
fprintf('Manual DFT matches fft(): %d\n',...
        max(abs(X - X_builtin)) < 1e-9);

% =========================================================
%  PLOTS
% =========================================================
k_ax = 0:N-1;

figure('Name','Experiment 4 - DFT and IDFT','NumberTitle','off');

subplot(2,2,1);
stem(k_ax, x, 'filled', 'LineWidth', 1.5);
title('Input Sequence x[n]');
xlabel('n'); ylabel('x[n]'); grid on;

subplot(2,2,2);
stem(k_ax, abs(X), 'filled', 'LineWidth', 1.5);
title('DFT Magnitude |X(k)|');
xlabel('k'); ylabel('|X(k)|'); grid on;

subplot(2,2,3);
stem(k_ax, angle(X)*180/pi, 'filled', 'LineWidth', 1.5);
title('DFT Phase  angle X(k)');
xlabel('k'); ylabel('Phase (degrees)'); grid on;

subplot(2,2,4);
stem(k_ax, x_rec, 'filled', 'LineWidth', 1.5);
title('Reconstructed x[n] via IDFT');
xlabel('n'); ylabel('x[n]'); grid on;

sgtitle('DFT and IDFT of a Sequence','FontWeight','bold','FontSize',12);
Exp 5 Linear Convolution using DFT
🎯 Aim – Question

How do you compute the linear convolution of two given sequences using the DFT approach (FFT and IFFT) in MATLAB, and verify the result using the built-in conv() function?

Principle: Y(k) = FFT{x[n]} × FFT{h[n]}  →  y[n] = IFFT{Y(k)}

MATLAB — exp5_linear_conv_dft.m 
% EXPERIMENT 5 - Linear Convolution using DFT (FFT/IFFT)
%
% Method : Y(k) = FFT{x[n]} * FFT{h[n]}
%          y[n] = IFFT{Y(k)}
% Verified against conv()

clc;
clear;
close all;

% Input sequences
x = [1, 2, 3, 4];
h = [1, 1, 1];

fprintf('Input x[n]: ');  disp(x);
fprintf('Input h[n]: ');  disp(h);

% =========================================================
%  LINEAR CONVOLUTION USING FFT / IFFT
% =========================================================
L = length(x) + length(h) - 1;    % required output length

X = fft(x, L);    % zero-pad to L and compute FFT
H = fft(h, L);
Y = X .* H;       % multiply in frequency domain
y_fft = real(ifft(Y));

% =========================================================
%  VERIFICATION USING conv()
% =========================================================
y_conv = conv(x, h);

fprintf('\nLinear Convolution using FFT/IFFT:\n');
disp(y_fft);
fprintf('Verification using conv():\n');
disp(y_conv);
fprintf('Results match: %d\n', max(abs(y_fft - y_conv)) < 1e-9);

% =========================================================
%  PLOTS
% =========================================================
figure('Name','Experiment 5 - Linear Conv using DFT','NumberTitle','off');

subplot(3,1,1);
stem(0:length(x)-1, x, 'filled', 'LineWidth', 1.5);
title('Input Sequence x[n]');
xlabel('n'); ylabel('x[n]'); grid on;

subplot(3,1,2);
stem(0:length(h)-1, h, 'filled', 'LineWidth', 1.5);
title('Impulse Response h[n]');
xlabel('n'); ylabel('h[n]'); grid on;

subplot(3,1,3);
stem(0:L-1, y_fft, 'filled', 'LineWidth', 1.5);
hold on;
stem(0:L-1, y_conv, 'rx', 'LineWidth', 1.5);
hold off;
legend('FFT/IFFT method','conv() verification');
title('Linear Convolution  y[n] = x[n] * h[n]');
xlabel('n'); ylabel('y[n]'); grid on;

sgtitle('Linear Convolution using DFT (FFT/IFFT)',...
        'FontWeight','bold','FontSize',12);

Exp 7 FIR and IIR Filter Design
🎯 Aim – Question

How do you design the following digital filters in MATLAB and plot their magnitude and phase responses?

Part i – IIR Low-Pass Filter (Passband edge: 4 kHz, Stopband edge: 6 kHz, Rp ≤ 1 dB, Rs ≥ 40 dB, Fs = 24 kHz)
  a) Butterworth filter    b) Chebyshev Type-I filter

Part ii – FIR Band-Pass Filter (fp1=20 Hz, fp2=30 Hz, fs1=10 Hz, fs2=40 Hz, Rp=0.5 dB, Rs=30 dB, Fs=100 Hz)
  a) Hamming Window    b) Kaiser Window

MATLAB — exp7_filter_design.m 
% EXPERIMENT 7 - FIR and IIR Filter Design
%
% Part i  : IIR LPF
%   Passband edge=4kHz, Stopband edge=6kHz, Rp<=1dB, Rs>=40dB, Fs=24kHz
%   a) Butterworth   b) Chebyshev Type-I
%
% Part ii : FIR BPF
%   fp1=20Hz, fp2=30Hz, fs1=10Hz, fs2=40Hz, Rp=0.5dB, Rs=30dB, Fs=100Hz
%   a) Hamming Window   b) Kaiser Window

clc;
clear;
close all;

% =========================================================
%  PART i : IIR LOW-PASS FILTER
% =========================================================
Fs  = 24000;   % sampling frequency (Hz)
Fp  = 4000;    % passband edge (Hz)
Fst = 6000;    % stopband edge (Hz)
Rp  = 1;       % passband ripple (dB)
Rs  = 40;      % stopband attenuation (dB)

Wp = Fp  / (Fs/2);    % normalized passband edge [0,1]
Ws = Fst / (Fs/2);    % normalized stopband edge [0,1]

% --- a) Butterworth LPF ---
[n_but, Wn_but] = buttord(Wp, Ws, Rp, Rs);
[b_but, a_but]  = butter(n_but, Wn_but, 'low');
fprintf('Butterworth LPF  Order = %d\n', n_but);

figure('Name','IIR - Butterworth LPF','NumberTitle','off');
[H, f] = freqz(b_but, a_but, 1024, Fs);

subplot(2,1,1);
plot(f, 20*log10(abs(H)+eps), 'LineWidth', 1.5);
title(sprintf('Butterworth LPF (Order = %d)  Magnitude Response', n_but));
xlabel('Frequency (Hz)'); ylabel('Magnitude (dB)');
xline(Fp,  '--r', 'Passband Edge','LabelVerticalAlignment','bottom');
xline(Fst, '--b', 'Stopband Edge','LabelVerticalAlignment','bottom');
grid on;

subplot(2,1,2);
plot(f, angle(H)*180/pi, 'LineWidth', 1.5);
title('Butterworth LPF  Phase Response');
xlabel('Frequency (Hz)'); ylabel('Phase (degrees)'); grid on;

sgtitle('IIR Filter - Butterworth LPF','FontWeight','bold');

% --- b) Chebyshev Type-I LPF ---
[n_cheb, Wn_cheb] = cheb1ord(Wp, Ws, Rp, Rs);
[b_cheb, a_cheb]  = cheby1(n_cheb, Rp, Wn_cheb, 'low');
fprintf('Chebyshev Type-I LPF  Order = %d\n', n_cheb);

figure('Name','IIR - Chebyshev LPF','NumberTitle','off');
[H, f] = freqz(b_cheb, a_cheb, 1024, Fs);

subplot(2,1,1);
plot(f, 20*log10(abs(H)+eps), 'LineWidth', 1.5);
title(sprintf('Chebyshev Type-I LPF (Order = %d)  Magnitude Response', n_cheb));
xlabel('Frequency (Hz)'); ylabel('Magnitude (dB)');

% =========================================================
%  PART ii : FIR BAND-PASS FILTER
% =========================================================
Fs2 = 100;
fp1 = 20;  fp2 = 30;
fs1 = 10;  fs2 = 40;
Rp2 = 0.5; Rs2 = 30;

df    = min(fp1-fs1, fs2-fp2);                      % transition width
N_ord = ceil((Rs2-7.95)/(14.36*(df/Fs2)));          % order estimate
N_fir = N_ord + mod(N_ord+1, 2);                    % ensure odd
Wn_bp = [fp1, fp2]/(Fs2/2);                         % normalized edges

% --- a) Hamming Window BPF ---
b_ham = fir1(N_fir-1, Wn_bp, 'bandpass', hamming(N_fir));
fprintf('\nFIR BPF Hamming Window  Order = %d\n', N_fir-1);

figure('Name','FIR BPF - Hamming','NumberTitle','off');
[H, f] = freqz(b_ham, 1, 1024, Fs2);

subplot(2,1,1);
plot(f, 20*log10(abs(H)+eps), 'LineWidth', 1.5);

title('FIR BPF - Hamming Window  Phase Response');

sgtitle('FIR Filter - Hamming Window BPF','FontWeight','bold');
